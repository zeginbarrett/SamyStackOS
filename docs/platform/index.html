THE SAMYSTACKOS PLATFORM

One management plane.
Many kinds of hardware.

SamyStackOS is being designed as a local-first operating environment for self-hosters, combining a core server platform with compatible nodes and specialized edge workers.

Product concept · Active development
PLATFORM ARCHITECTURE

A clear separation between control and execution.

Not every device should run the same software. The platform can assign compatible work to the right class of hardware.

PHYSICAL TO DIGITAL

The rack is just the beginning.

The management view follows your hardware wherever it lives.

From one mini PC to a mixed collection of machines, the goal is to keep the system organized without forcing all hardware into the same execution model.

  • Runs core services on capable server hardware
  • Can enroll different worker classes through separate agents
  • Designed around authenticated management and explicit permission
  • Shows hardware and software together with a coherent inventory

DESIGN DIRECTION

Practical, not magical.

The interactive console is a design preview using sample information. Product modules will be validated and released in stages; a single operating system does not make every application runnable on every CPU architecture.

For example, Android phones could execute compatible, isolated ARM tasks. They are not drop-in replacements for x86 hypervisors, and their memory cannot be pooled as though they were one physical computer.
