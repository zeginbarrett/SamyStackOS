THE DIFFERENCE

A worker in your cluster. Not just a screen.

01 / ENROLL

Install and pair

Install the proposed SamyStack Worker app on a spare Android phone. Approve the cluster pairing and choose what resources that phone is permitted to share.

02 / ADVERTISE

Report real capacity

The phone reports CPU architecture, available memory, battery level, charging state, network quality, thermal state and which job runtimes it actually supports.

03 / COMPUTE

Execute assigned tasks

The scheduler sends only compatible, bounded job chunks. The Android app does the processing locally, returns the output and can be paused by its owner.

04 / RECOVER

Keep the cluster moving

When a phone disconnects, overheats or runs low on charge, unfinished tasks can be retried on another eligible worker rather than blocking the whole job.

DISTRIBUTED JOBS

What phones could actually process.

IMAGE PIPELINE

Photo processing

Resize images, generate thumbnails, create previews and run independent image conversions in parallel.

FILE OPERATIONS

Hashing & compression

Assign independent file checksums, integrity verification and compatible compression or archive tasks.

AI / ARM WORKERS

Lightweight inference

Run supported small on-device machine-learning models where the CPU, memory and available acceleration allow it.

BATCH COMPUTE

Parallel calculations

Break simulations, indexing or data-processing jobs into independent tasks, then gather the results centrally.

MEDIA PROCESSING

Media job chunks

Queue compatible audio conversions or video segments where codecs, thermal capacity and input sizes make sense.

EXTENSIBLE RUNTIMES

Custom task packages

Eventually add reviewed ARM-native or sandboxed task types with strict permissions, quotas and versioning.

Workers do not pool their RAM into one shared memory space. A Windows VM, a random x86 executable or a single indivisible task cannot simply be moved onto an unmodified Android phone. Work must be compatible with its processor and app execution environment, or split into supported independent tasks.

THE WORKER APP

Built for aging phones, with sensible limits.

Owner-controlled sharing

Opt in to processing, set a CPU and memory budget, allow Wi-Fi only, choose charging-only mode, and pause or leave the cluster at any time.

Thermal & battery protection

Throttle or stop tasks when a phone heats up, battery falls below a chosen threshold or the system signals resource pressure.

Secure jobs, not remote shell

Authenticated pairing, encrypted transport, signed task definitions and restricted runtimes are design requirements. Worker enrollment does not grant arbitrary device control.

Respect Android's scheduler

Use supported foreground execution and scheduled work. Android can still stop or limit background jobs; continuous operation is not guaranteed, especially on newer releases.
