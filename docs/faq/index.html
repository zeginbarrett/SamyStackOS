GETTING STARTED

The essentials, explained.

Can I install SamyStackOS today?

There is not yet a public production-ready installation. The project is in active development; the site includes design previews and an interactive sample console.

Does it only work with a rack?

No. Rack hardware is used as an example of an organized setup. The platform's intended compatibility depends on CPU architecture, operating system, supported devices and software—not the physical enclosure.

Can an Android phone really do part of a cluster workload?

For compatible, independent tasks, yes in principle. A worker app could execute ARM-native or supported portable tasks, subject to Android limits and the device's power, RAM and thermal state. The SamyStackOS Android worker app is currently planned, not released.

Can Android phones run the same VMs as my mini PCs?

No. Standard x86 KVM virtual machines are not portable to ordinary Android phones. SamyStackOS would distinguish virtualization hosts from task-based Android workers.

Can all the phones combine their memory into one giant pool?

No. Each device keeps its own physical RAM. A distributed application can divide tasks and combine results; it cannot treat all the phones as one shared-memory computer.

Does it need a cloud subscription?

Local-first management is the intended direction. Exact account, remote access and support policies have not been finalized.

Can it manage Raspberry Pi and ESP32 hardware?

The plan includes Raspberry Pi services and device-specific ESP32 integrations. ESP32 controllers are better suited to sensors, controls and messages than to server virtualization.

Are the devices shown in the demo actually connected?

No. The demonstration uses illustrative hardware records, workloads and status information. Its actions do not connect to or change real machines.

Is this designed to replace Proxmox or Unraid?

SamyStackOS is exploring comparable infrastructure workflows with broader mixed-hardware integration. It is not currently a finished production substitute for either system.

When is the release date?

A validated release date has not been announced. The roadmap reflects development priorities, not guaranteed shipping dates.
