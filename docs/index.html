FAQ / 04

THE DETAILS.

IS SAMYSTACKOS AVAILABLE TO INSTALL?+

Not as a public, stable release yet. This website presents the direction of the project and an illustrative interface—not a working online management console. Follow the repository for source and release updates.

IS THIS AN ALTERNATIVE TO PROXMOX OR UNRAID?+

That's part of the long-term ambition: an approachable homelab platform that brings together virtualization, containers and cluster management. It is not currently a replacement for either production system.

WHAT HARDWARE WILL IT SUPPORT?+

The current target is common x86-64 mini PCs and home-server hardware with Debian as the foundation. Tested hardware and installation requirements will be documented as the project matures.

IS THIS SITE A LIVE OS DASHBOARD?+

No. The dashboard above is an interactive design demonstration using sample data. It does not connect to servers or perform real management actions.
