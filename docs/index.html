A FEW GOOD QUESTIONS

The details.

The vision is ambitious. Here's what you should know today.

Can I install SamyStackOS right now?+

Not as a public, production-ready release. The project is in early development, and this website shows the planned experience. Installation details will be provided when a release is ready.

Is it intended to replace Proxmox or Unraid?+

SamyStackOS is an independent project aiming to combine approachable local-server management with virtualization, containers, storage and eventually clustering. It is not currently a production-ready replacement for those systems.

Will I need expensive hardware?+

The design target is everyday 64-bit x86 mini PCs and home servers. Exact minimum specifications and compatibility will be published as hardware support is validated.

Is the dashboard above real?+

It's a functional website demo with illustrative values—not a live server console. Tabs and demo interactions work, but they do not manage machines or save changes.

Will it work without a cloud subscription?+

Local-first management is a core goal. Account, remote access and security details have not been finalized yet.
