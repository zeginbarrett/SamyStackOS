05 / QUESTIONS

Good questions.
Straight answers.

Can I download SamyStackOS today?+

Not yet. SamyStackOS is an early-stage project. Follow the GitHub repository for code, updates and any future release announcements.

Is this a replacement for Proxmox?+

That's the ambition: a simpler, integrated homelab management alternative with virtualization and clustering features. It is not currently a production-ready substitute for Proxmox VE.

What hardware will it support?+

The initial direction targets common 64-bit x86 mini PCs and similar home servers, with a Debian-based foundation. Minimum requirements and validated hardware will be published as development progresses.

Will I need a cloud account?+

The design goal is local-first management of your own machines. Exact account, remote-access and security capabilities will be documented as the software becomes available.
