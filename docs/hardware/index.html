HARDWARE ECOSYSTEM

More than a server rack.

SamyStackOS is being built around the idea that different machines belong to one manageable system, from core compute nodes to edge devices and dedicated task workers.

Product concept · Active development
THE HARDWARE STACK

Give every device a useful role.

The same workspace can represent different types of nodes without pretending they all run identical software.

Managed across the entire lab.

Power protection, network infrastructure, compute, edge gateways and small connected devices all become easier to understand when they are represented together.

  • Mini PCs and home servers for core workloads
  • Raspberry Pi for compatible ARM services and gateways
  • Android phones for opt-in distributed processing
  • ESP32 endpoints for sensors, controls and audio
  • Network switches, gateways and power equipment as managed infrastructure
