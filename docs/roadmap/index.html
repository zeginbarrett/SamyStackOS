ROADMAP

Building the platform, one verified piece at a time.

SamyStackOS is in early development. This roadmap distinguishes work underway, planned modules and longer-term research instead of presenting concepts as finished releases.

Product concept · Active development
DEVELOPMENT PHASES

Clear priorities, visible progress.

There is no public production-ready release at this stage.

NOW / FOUNDATION

Core operating system & interface

Debian-based packaging, first-run setup, host visibility, navigation, service manager and dashboard development.

IN PROGRESS
NEXT / CORE

VM, container and storage workflows

Working host APIs, console operations, resource controls, network features, storage monitoring and backup integration.

PLANNED
NEXT / CLUSTER

Multi-host discovery and placement

Approved node enrollment, workload placement, observability and scheduler foundations.

PLANNED
LATER / EDGE

Raspberry Pi, Android & ESP32 integration

Specialized workers and adapters for distinct operating systems and device classes, with compatibility testing.

RESEARCH / PLANNED
LATER / RESILIENCE

Automation, recovery & availability

Safe orchestration, job retries, snapshots, backups, app templates and selected high-availability goals.
